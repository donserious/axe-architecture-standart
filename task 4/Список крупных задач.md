Для эффективного планирования и реализации проекта, связанного с автоматизацией открытия депозитов и накопительных
счетов, можно выделить крупные задачи для каждой из систем, упомянутых в архитектурном решении (ADR). Ниже представлен
список крупных задач для каждой системы:

### 1. Система интернет-банка

- **Разработка интерфейса для открытия депозитов и накопительных счетов**:
    - Создание пользовательского интерфейса, который позволит клиентам легко открывать депозиты и накопительные счета.

- **Интеграция с новым сервисом для получения актуальных ставок**:
    - Реализация механизма получения актуальных ставок из посторонней системы через новый сервис в рамках АБС.

- **Автоматизация процесса открытия депозитов**:
    - Разработка логики для автоматической обработки заявок на открытие депозитов без участия бэк-офиса.

- **Реализация механизма подтверждения операций**:
    - Внедрение системы подтверждения операций через СМС или другие каналы.

- **Обеспечение безопасности данных**:
    - Реализация механизмов шифрования и защиты данных при передаче информации.

### 2. Система АБС (Автоматизированная банковская система)

- **Разработка нового сервиса для получения ставок**:
    - Создание сервиса, который будет получать актуальные ставки из внешней системы и передавать их в интернет-банк и
      кол-центр.

- **Интеграция с существующими модулями АБС**:
    - Обеспечение совместимости нового сервиса с текущими модулями АБС для обработки заявок на депозиты.

- **Оптимизация базы данных**:
    - Проведение работ по оптимизации базы данных для обеспечения высокой производительности при увеличении нагрузки.

- **Разработка API для взаимодействия с интернет-банком**:
    - Создание API, который позволит интернет-банку взаимодействовать с АБС для подтверждения условий депозитов.

### 3. Кол-центр

- **Обучение сотрудников кол-центра**:
    - Проведение обучения для сотрудников кол-центра по новым процессам и актуальным ставкам.

- **Интеграция с системой получения ставок**:
    - Настройка доступа к актуальным ставкам для сотрудников кол-центра через новый сервис или файлы.

- **Разработка скриптов для консультирования клиентов**:
    - Создание скриптов и инструкций для сотрудников кол-центра, чтобы они могли эффективно консультировать клиентов по
      новым условиям.

### 4. Партнёрский кол-центр

- **Настройка процесса передачи ставок**:
    - Разработка механизма передачи актуальных ставок в виде файлов для партнёрского кол-центра.

- **Обучение сотрудников партнёрского кол-центра**:
    - Проведение обучения для сотрудников партнёрского кол-центра по новым процессам и условиям депозитов.

### 5. Система мониторинга и аналитики

- **Разработка системы мониторинга**:
    - Создание системы мониторинга для отслеживания работы новых процессов и выявления узких мест.

- **Анализ производительности**:
    - Внедрение инструментов для анализа производительности и сбора обратной связи от пользователей.
