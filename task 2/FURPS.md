|     | Необходимо устранить задержки при загрузке справочных данных (сейчас более секунды). | Оптимизация производительности улучшает пользовательский опыт и снижает нагрузку на систему. |
|     | Предусмотреть равномерное горизонтальное масштабирование и распределение запросов между серверами и ЦОД. | Это поможет избежать перегрузки системы и обеспечит стабильную работу при увеличении нагрузки. |
| S   | Поддерживаемость (Supportability)  |              |
|     | Использовать существующие технологии (MS SQL, Oracle) для доработок. | Это снижает риски и затраты на обучение сотрудников новым технологиям. |
|     | Разработать документацию для дальнейшего расширения системы. | Документация необходима для упрощения поддержки и развития системы в будущем. |

|     | Учитывать опыт команды АБС в Java-стеке для возможных интеграций. | Это позволит использовать существующие навыки и ускорить процесс разработки. |
| +R  | + Ограничения (Restrictions)      |              |

|     | Избегать прямой работы интернет-банка с API АБС в новом процессе. | Это снизит риски перегрузки АБС и повысит надежность системы. |
|     | Учитывать, что АБС может масштабироваться только вертикально. | Это важно для планирования архитектуры и распределения нагрузки. |
|     | Обеспечить совместимость новых технологий с существующими платформами разработки. | Это минимизирует затраты на интеграцию и обучение сотрудников. |
|     | Учитывать ограничения производительности монолитной архитектуры интернет-банка.| Это важно для оптимизации работы системы и планирования архитектуры. |
